## Work Log

- The `/models` route uses `model-studio.page.ts`; the unused `models.page.ts` is not the catalog. A missing closing `<section>` made the dev JIT template invalid even though the production build passed. It is fixed and the live route opens.
- `OPTIONS` only allowed a subset of implemented POST routes. Browser JSON requests to `/api/runtime/load`, `/api/runtime/unload`, `/api/runtime/chat`, and `/api/runtime/command` therefore failed before the POST was sent. These routes are now in the explicit CORS preflight allow-list, with a regression test covering the runtime routes and headers.
- The Runtime Manager backend native `<select>` could stay visually at its blank placeholder while backend options arrived asynchronously. The selected backend is now marked on its option and asserted by the UI structural check.
- Coverage snapshot: the full Python suite passed at 254 tests before the final contract case; the new contract and related focused tests pass separately. Angular typecheck/build, 15 template parses, 13 navigation routes, runtime layout, model configuration/sorting, and Chat/Agent Playwright smoke pass. A no-generation contract probe against the active server returned SSE successfully without request_id, while Gemma remained loaded. No inference or model reload was started.

- The Vite development entry loads Angular's compiler only in dev mode so lazy route components can be inspected/compiled; production remains AOT and the compiler is tree-shaken from the production bundle.
- `GET /api/logs?limit=` was accepted by the first query allow-list but rejected by the second. Both now agree; an HTTP-level regression test covers the exact page request.
- The supplied llama-server dump shows SIGABRT in `llama_params_fit`; the installed server advertises fit enabled by default. The safe default is now disabled in the command builder unless the user opts in.
- The apparent paired GGUF entries are often a base model and a same-name `mmproj` vision projector, not two model shards. Shards are separately recognized via GGUF split metadata.
- No model inference, LLM benchmark or real GPU load was started during this work.
